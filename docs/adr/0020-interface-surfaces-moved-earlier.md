# ADR-0020 — 接口面提前：UI 视图注册表骨架与 handler 上下文位（M3）

状态: accepted
日期: 2026-10-12 | 关联: 横切规则 7（`development-plan` §"后置分层"）、overview §12 E1、
§8（一套会话层两种传输）、§13 未决项 5（wuu"配对即授予控制权"）、`ui/README.md`

## 结论

两处按 `development-plan` 横切规则 7（"晚做会不会回头改已完成模块的接口——会就是接口"）
判为接口面，从原定时点提前：

1. **UI 视图注册表骨架提前到 M3**（不是 E1）：M3 落一个 `PanelDescriptor` 声明 +
   一个渲染分发点 + "新面板只能登记、不得改外壳"的护栏测试。E1 只剩"补 token/主题
   与加面板"，不从 0 建。
2. **serve 的 handler 一律收 `HandlerCtx` 对象**（M2.3 的 serve 雏形就按此写，不留
   散装参数）：字段包含 `workspace_id` / `thread_id` / `permission_mode` /
   `client_id` / **`principal`**。`principal` 本期只承担"这台机器上这个会话属谁"的
   **传递与回显**（`initialize` 回显 + 日志 `trace_id` 字段），**不含任何鉴权判定**——
   鉴权体系仍按 §14 后置到对外暴露之前（那时必须有 ADR）。
3. 树形检索依赖的证伪提前：`tree-sitter` 能否在 py3.12/3.13 装上是 M7 `code_index`
   的选型前提（overview §4 已登记为"待验证风险"），安排一次独立半小时冒烟，
   结果落 `docs/notes/`；不阻塞 M2/M3（M2.2 的 `search` 是正则遍历，零依赖）。

## 理由与取舍

- **注册表**：横切规则 7 已把"UI 视图注册表与 token 层"明文列为**必须与内核同期定**的
  接口面，但 overview §12 E1 又把"注册表成型"排在 M8 之后——两份文档互相矛盾，按
  AGENTS 偏离纪律取"更早的那个"并回写两处。后果评估很具体：M3（Files/Review）、
  M4（看板）、M5（验收卡）、M6（引擎选择）都要往 UI 塞面板；没有分发点时每个面板
  只能各自硬编码接进外壳，E1 再建注册表就是"重写已完成模块的接口"。
- **`principal` 为什么不算投机留门**：AGENTS §二 判据第 3 问要求"已有第二个真实使用者"。
  它今天就有两个消费者——`initialize` 的回显面与日志的 `trace_id` 字段（AGENTS §四
  明文要求结构化字段带 `trace_id`）；且 handler 无论如何都需要一个参数对象来携带
  workspace/thread/mode，把身份放进它是**少一个平行形状**，不是多一个空壳。
  真正的鉴权逻辑一行都不写。
- **代价**：M3 多一个注册表骨架（约一个 descriptor 类型 + 一个分发函数 + 一条护栏）；
  handler ctx 让方法签名比"逐个参数"略啰嗦。两者都远比四个里程碑后回头改面板便宜。

## 被否决的选项

- **注册表照原计划放 E1**：与横切规则 7 直接冲突，且 E1 时已上线 4+ 个面板，
  迁移成本是重写而非搬运。
- **只留 `client_id` 不留 `principal`**（"M8 再加"）：M8 要往每个 handler 里插归属
  校验——横切所有已跑通 handler 的重写级改动，正是横切规则 7 定义的反例。
- **现在就写鉴权判定（token 校验、归属拒绝）**：M2.3 只做本机 stdio/localhost，
  无对外暴露，写判定即违反 §14"不留的门"与"不做无消费者的实现"。
- **现在引 tree-sitter 做代码检索**：M2.2 的 `search` 零依赖且够用（正则 + 修订号绑定），
  为 M7 的能力提前引一个有停维依赖风险的包是把风险请进核心。

## 适用条件与失效条件

**适用**：M2.3 的 serve handler 签名、M3 的 serve/UI 接口面。
**触发重新评审**：① 任何对外暴露（自托管网页、远程）动工前，`principal` 必须升级为
真实归属校验并落新 ADR（§14 明令）；② M3 若出现第二种宿主传输（WS/SSE）而 handler ctx
字段不足以表达连接属性 → 扩字段而非加参数；③ 冒烟证明 `tree-sitter` 装不上 →
`code_index` 改用 grep/ctags 类方案并回写 overview §4。
