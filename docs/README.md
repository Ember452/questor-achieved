## 写作规矩

- **契约唯一来源**：数据模型、状态机、协议以 `architecture/overview.md` §7 §8 及其后续
  展开篇为准，其他文档只引用不复述。
- **先文档后代码**：改契约先改文档并递增版本号，代码跟随；顺序不可反。
- **文档视距冻结**：非当期里程碑的模块内部设计篇不新增、不修订，只能在对应模块开工时改，
  防止用写文档代替交付。
- 每个"已决定"必须能追溯到 ADR 或 overview 条目；每个"没决定"显式写在 overview §13，
  **不许默默替用户选**。
